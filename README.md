## cubmart

cubmart is a fully responsive front-end web application for an online e commerce market i mdae for  Horizons event.

## features inlude:
**responsive design:** cubmart works on any device you have including mobiles, tablets, laptops and bigger monitors
**interactive UI components:** buttons like a togglable shopping cart, search bar and even a navbar on smaller devices
**dynamic images:** Utilizes Swiper.js to smoothly showcase products and customer reviews.
**login form with validation:** in the togglable profile section if you choose "create account" you will be directed to the "sign up page" where you can make an account with form validation

## tech used:
* **HTML5**: for the page markup
* **css3**: for the styling of the page
* **javascript(vanilla):** used with DOM manipulation for interactive elements and form validation logic
* **Third-party Assets**
  *  [Swiper.js](https://swiperjs.com/) (v12) for the sliders.
  *  [FontAwesome](https://fontawesome.com/) (v6.4.0) for the iconography.
  *   [Google Fonts](https://fonts.google.com/) (Poppins) for the typography.
